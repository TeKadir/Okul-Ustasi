OKUL USTASI - WINDOWS UYGULAMASI (.exe) NASIL DERLENIR

Gerekenler: Node.js (https://nodejs.org, LTS sürümü) - bir kez kurulur.

1) Bu klasörde (windows-uygulama) bir komut penceresi aç.
2) Bir kez:   npm install
3) Denemek için (exe üretmeden uygulamayı açar):   npm run baslat
4) .exe üretmek için:   npm run exe
   -> Hazır dosya ../uygulama/Okul-Ustasi.exe konumuna kopyalanır.
      Sitedeki "Uygulamayı İndir" düğmeleri bu dosyayı indirir.

Siteyi (html/css/js) değiştirince tekrar "npm run exe" çalıştır;
site dosyaları uygulamaya otomatik kopyalanır.

Site internette yayınlanırsa main.js içindeki SITE_ADRESI satırına
adresi yaz: uygulama o zaman canlı siteyi açar.
